# 몽골 제국 3편 기획 - 제베·수부타이의 서쪽 원정, 칼카강 1221~1223 (2026-11-04 2판, 사용자 확인 전)

## 방향
- **방법론 편: 몽골군의 거짓말.** 기병 2만이 처음 보는 나라들을 이긴 무기는 활보다 "말"이었다. 등을 보이는 거짓말(거짓 후퇴), 선물의 거짓말(동맹 쪼개기), 사신의 거짓말, 약속의 거짓말을 장마다 하나씩 보여 준다. 결과는 짧게
- 2편 끝("제베와 수부타이가 이끈 기병 2만 명")에서 바로 이어짐
- 훅은 **시청자에게 직접 묻기**. 답이 뻔한 전술 퀴즈가 아니라 정답이 없는 선택("믿겠습니까?")
- 거짓 후퇴는 1편에서 단계별로 자세히 했으니, 여기선 변형만: 조지아 = 숨은 반쪽(매복), 칼카 = 9일 끌어 행렬 늘이기
- 옛 칼카강 영상(10-20, `uploads/mongol-02-kalka-old.json`)과 소재는 같지만 새로 만듦
- 캐릭터: 제베, 수부타이, 루수단(조지아 여왕), 쾨텐(킵차크 칸), 므스티슬라프 대담공(갈리치아), 므스티슬라프(키예프), 몽골 사신
- 길이 목표 10~11분

## 영상 전체를 끄는 질문
**"몽골의 말을 믿은 쪽도, 믿지 않은 쪽도 왜 둘 다 졌을까?"**
답(5장 끝·6장): 몽골의 말은 믿게 하려고 한 말이 아니라 **상대를 움직이게 하려고** 한 말이었다. 믿은 킵차크는 동맹을 버리고 떠났고, 믿지 않은 루스는 성을 나와 초원으로 나왔다 - 둘 다 몽골이 원하던 곳으로 움직였다.

## 훅 (2판)
```
▶ 초원의 큰 천막 앞, 말에서 내리는 몽골 사신 열 명 / 맞은편 의자에 앉은 루스 공후들, 서로 눈치를 봄
N: 당신을 치러 온 군대가, / 사신을 보내 이렇게 말합니다. ⏸0.3
몽골 사신: "우리는 당신들과 싸울 생각이 없다."
N: 믿겠습니까? ⏸1 / (▶ 지도로 전환: 지금의 우크라이나 초원 - 남쪽 킵차크 천막들, 북쪽 루스의 나무 성들) 1223년, 지금의 우크라이나 초원. / 이 말을 믿은 사람들이 있었고, / 믿지 않은 사람들이 있었습니다.
▶ 화면 반 나누기: 왼쪽 킵차크 천막(고개 끄덕이며 선물 수레를 받음) / 오른쪽 루스 성(사신 앞에서 칼을 뽑음) → 양쪽 깃발이 동시에 쓰러짐
N: 그리고 둘 다, / 같은 기병 2만 명에게 무너졌습니다. ⏸1
N: 몽골 제국 시리즈 3편, / 시작합니다.
```
(약 20초. 첫 줄이 질문, 위치는 둘째 줄 - 검사 규칙 통과. 훅의 질문은 3장·4장·6장에서 답함)

## 정해 줘야 할 것
1. **6장 판자 잔치**: 인물 최후·명장면이라 빼는 기준에 걸리지만, 이 편에선 "약속의 거짓말"이라는 방법의 마지막 칸. tvN 칼카 편(116만)도 제목에 건 장면. 넣을지(제안: 넣음, 말로만·실루엣), 한 줄로 할지, 뺄지
2. **2장 데르벤트**: 40초로 짧게(제안) vs 1장 끝에 한 줄로 합치기
3. 볼가 불가르에게 진 싸움(1223, 귀환길)은 넣지 않음(제안) - 2편에서 파르완을 뺀 것과 같은 이유
4. 크림반도 수다크 습격·베네치아 상인과의 거래설(유럽 상인이 몽골에 정보를 줬다는 설)은 재밌지만 뼈대가 약해 뺌(제안). 원하면 2장 뒤에 "그런데 이 원정에는 유럽인 협력자도 있었다고 전해집니다"로 30초
