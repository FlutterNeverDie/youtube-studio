# 사고 기록 (같은 실수 반복 금지)

검사 스크립트가 이미 자동으로 막는 사고는 지웠다 - 스크립트가 곧 기록이다(아래 "자동으로 막는 것"에 한 줄씩). 여기에는 **사람(Claude)이 챙겨야 하는 것**만 남긴다. 옛 경위는 git 이력에 있다 (2026-11-04 정리).

## 렌더
- **렌더 중에 렌더 스크립트를 고치지 않는다** - 실행 중인 bash가 엉뚱한 줄을 읽어 깨진다
- **실패를 감지해야 하는 단계는 파이프(`| tail`)로 잇지 않는다** - 앞 단계가 실패해도 성공으로 넘어가 깨진 2편이 올라간 적 있음
- **조각 렌더는 동시에 2개까지.** 4개면 크롬 과부하로 오른쪽 띠 깨짐. 깨진 프레임 다시 찍기는 `remotion still`로 **한 장씩**(동시에 찍으면 또 깨짐)
- **먹선 필터(`url(#kit-ink)`)를 단 컴포넌트는 한 화면에 수십 개까지.** 수백 개면 화면 조각이 비어 깜빡임 → 많은 병사는 한 svg 안의 작은 그림(`KhG`·`MoG`)으로
- **영상을 이어 붙일 때 `-c copy` 금지.** 시간 단위가 다른 영상을 그대로 붙이면 영상이 중간에 끊기고 소리만 남는다. 같은 설정으로 다시 인코딩(libx264·30fps·`-video_track_timescale 90000`·AAC 48k) 뒤 붙이고, 길이가 아니라 **영상 프레임 수**(`ffprobe -count_packets`)와 뒷부분 화면으로 확인
- **깨짐 판정은 "튀었다 돌아옴"과 "아홉 칸 같음" 중 하나라도 걸리면 깨짐.** 한쪽만 믿고 고친 프레임을 되돌리지 말 것
- 소리만 고칠 때는 `remotion render … --codec=wav`로 소리만 뽑아 영상에 다시 붙인다(-c:v copy)
- 백그라운드 렌더·목소리 작업을 새로 돌리기 전에 **예전 작업이 끝났는지(죽였는지) 확인** - 남은 작업이 파일을 지우거나 덮어쓴 적 있음 (2026-11-03). 같은 폴더를 건드리는 작업은 동시에 돌리지 않는다(draft-lines 동시 실행이 voice-level에서 충돌)

## 대본·목소리
- **줄을 끼워 넣으면 다른 언어 voice/i18n 파일의 번호도 같이 옮긴다** - 번호가 밀리면 예전 대사가 엉뚱한 줄에 붙어 장면 길이가 틀어진다(draft-lines.py가 못 잡음)
- **check-draft 경고를 그냥 넘기지 않는다** - 2편에서 "원인 없는 결과" 경고가 오탐 경고들 사이에 묻혀 지나갔다
- **장마다 따로 볼 때 괜찮아도 이어 보면 걸리는 것**: 같은 연도 반복, 갑작스러운 항복, 해결만 있고 문제가 약함, 대사엔 있는데 화면엔 없는 장면(길잡이), 장 끝에 결과 한 줄 없음 → `11-대본-점검.md`
- 장면 안 타이밍은 **영어(기본 트랙) 기준**이어야 한다. 장 파일에 한국어 초를 적을 때는 `tl(id, 초)`로(렌더 언어의 같은 조각 자리로 옮겨 줌). 영어 대본도 한국어와 같은 자리에서 `/`로 끊는다
- 시험판·예고편이라도 (1) 그 시점의 인물 상태 그림(stages) (2) 장면 전환 (3) 웃음 장면은 박자·반응·효과음 - 셋 없이 만들지 않는다

## 소리
- **배경 바닥 소리는 조건부 블록(`{map < 1 && …}`) 밖에 둔다** - 안에 두면 장면이 바뀔 때 끊긴다. 장 카드를 뺀 장(NO_CARD)은 경계에 바닥 소리가 있는지 꼭 확인
- 대사 안 쉼(`/`)에서 효과음이 먼저 끝나면 무음이 생긴다 - 바람·발굽 바닥을 장면 끝까지 깐다
- 무음 위치를 진단할 때는 0.1초 단위로 소리 크기를 재서 확인(눈짐작 진단이 틀린 적 있음)
- 브금 곡 꼬리가 스스로 줄어드는 곡은 반복 이음새에서 꺼질 수 있다 - 곡마다 꼬리 길이가 다르면 곡별 값을 둘 것
- **더빙 트랙**: 목소리는 더빙 언어, 배경은 영어(lang=en)로 렌더하되 브금 줄임은 더빙 언어 기준(duck=<언어>). `scripts/dub-track.py`가 이렇게 한다. 배경을 더빙 언어로 렌더하면 효과음이 영어 화면과 어긋나고, 영어 duck이면 긴 더빙 대사 밑에서 브금이 다시 커진다

## 업로드·유튜브
- **`youtube.mjs auth` 뒤에는 출력의 "채널: ..."이 ReStory Worlds인지 본다.** 개인 채널 "유튭"을 골라 재생목록이 엉뚱한 채널에 만들어진 적 있음(영상 수정은 관리자 권한이라 통과해서 못 알아챔)
- API가 "성공"이라 해도 결과를 목록으로 다시 확인한다 - 인도네시아어 자막이 성공 메시지 뒤에 없었던 적 있음(`caption`은 이제 스스로 확인)
- 채널의 **자동 더빙 허용은 꺼 둔다**(설정 → 채널 → 고급 설정). 켜져 있으면 유튜브가 21개 언어 자동 더빙을 만든다. 우리 트랙인지는 ID(`ko.10`)로 구분이 안 돼 들어서 확인
- 새 영상은 공개 뒤 검색 색인까지 1~3일. 상태 확인은 `node scripts/youtube.mjs status <영상ID>`
- 음성 트랙·언어별 썸네일·썸네일 비교 테스트는 API가 없어 스튜디오에서 사용자가 올린다
- 쇼츠 설명란 링크는 누를 수 없다 → 긴 영상 연결은 스튜디오 "관련 동영상"

## 기울인 지도 장면 - 엔진 주의점 ([map] 세션 정리)
1. 돌격(charge) 뒤 hold로 바꾸면 앞줄이 뒤로 빠진다. 적을 덮은 채 끝내려면 마지막 상태도 charge
2. 일부러 겹치는 무리는 press:false와 layer를 함께
3. count를 짧은 구간에서 크게 줄이면 한꺼번에 쓰러진다 - 줄이는 구간을 길게
4. 방향을 100° 넘게 꺾으면 대형이 뒤집힌다 - 중간 키로 두 번에 나눠 꺾기
5. 병사 키 7~11px 구간(점 ↔ 실루엣)을 오래 지나면 색감이 바뀌어 보인다
6. 얼굴 메달이 전투 한가운데를 가릴 수 있다
