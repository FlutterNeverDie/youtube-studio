# 대본 점검표 (2026-11-03 시작)

장 대본을 사용자에게 보여 주기 전에 장마다 아래를 하나씩 따진다.
다 통과하면 `python3 scripts/check-draft.py episodes/<편> <장> --stamp`로 도장을 찍는다.
- 도장은 그 장 대사로 만든 해시라서, 대사를 고치면 풀린다. 풀리면 다시 따진다.
- 도장이 없거나 풀려 있으면 check-draft가 오류를 낸다. 2편부터 적용한다.
- 기계로 잡을 수 있는 것은 check-draft가 따로 잡는다: 같은 연도 되풀이, 훅 위치 소개, 원인 없는 결과, 막연한 장 끝.
- AI 티 · 번역투는 `python3 scripts/check-lines.py episodes/<편> uploads/<편>.json`이 언어마다 잡는다(규칙 `docs/guide/locales/<언어>.rules.json`, 줄 사이 반복 · 어림말 이어짐 · 훅 되풀이 · 업로드 태그와 세기 표기). draft-final 1단계와 Openology check-cuts가 부르고, 지금은 알리기만 한다(2026-11-09, 사용자가 확인하면 막는 검사로). 사람이 볼 것은 `locales/<언어>.md`의 "AI 티 · 번역투" 절
- 아래 질문은 사람 판단이 필요한 것만 모았다.

## 질문 (check-draft --stamp가 이 목록을 그대로 읽어 보여 줌)
- [ ] 원인 → 결과가 이어지나: 항복·함락·도망 같은 결과 앞에, 왜 그렇게 됐는지 한 줄과 한 장면이 있나 (2편: "작은 도시를 싸우지 않고 항복시키고"가 뜬금없었음 → 대군에 겁먹음 → 사신의 약속 → 성문을 엶)
- [ ] 방법마다 "문제 → 제약 → 해결"이 다 있나: 해결만 말하고 왜 필요한지 빠지지 않았나 (2편: "우물을 나눠 쓴다"만 있었음 → 말이 사람보다 훨씬 많음 → 우물은 하루 물이 정해짐 → 뒤 부대는 빈 우물)
- [ ] 대사가 말하는 행동이 화면에 직접 나오나: "길을 알려 주었다"면 길을 짚는 장면이 있나, 지도 점선으로 때우지 않았나 (2편: 길잡이가 행렬 맨 앞에서 안내하는 장면 추가)
- [ ] 장마다 마지막에 그 방법의 결과가 한 줄 있나 (2편 4장: "소문이 성문을 열었다" 뒤에 "손쉽게 호라즘을 차지" 추가)
- [ ] 다음 장으로 넘기는 대사에 무엇인지 이름이 붙어 있나: "~방법이 있었습니다"처럼 막연하지 않나 (2편: "성을 부수지 않고 이기는 방법" → "심리전에도 강했습니다")
- [ ] 인용·협박·통보는 구체적이고 센가: 한 줄 요약("버티면 모두 죽는다")이 아니라, 무엇을 어떻게 하겠다는 말투인가. 화면 순서와 같은 순서로 (2편: 빼앗고 → 베고 → 불바다)
- [ ] 표현이 사실과 맞나: 포로를 "얻었다", 끌려간 사람을 "도왔다"처럼 순하게 바꿔 말하지 않았나 (2편: 길잡이는 사실상 포로 → "골라 앞세웠다", "짚어야 했다")
- [ ] 훅: 처음 보는 나라는 어디 있는 나라인지부터 말하나, 질문은 이 편의 핵심("어떻게 함락했나")을 그대로 묻나, 핵심이 아닌 숫자("2년도 안 돼")로 힘을 빼지 않았나
- [ ] 같은 숫자·연도가 화면과 대사에 연달아 나오지 않나: 카드에 뜬 연도를 대사·큰 숫자로 또 말하지 않기 (2편: 1220이 세 번 연속)
