# 그림 스타일 후보 (2026-10-28)

사용자가 Lemo-Opuscar 갤러리를 보고 고른, 나중에 그 시대 편이나 장면에 시험해 볼 그림 스타일.
지금 1편은 "코드로 그린 새 그림체(A) + 옛 그림을 찢은 종이(B)"로 만들었다 (02-제작-결정.md 인물 캐릭터). 아래 스타일은 이걸 바꾸는 게 아니라 **특정 시대·장면에 섞어 쓰는 후보**다.

## 출처
- Lemo-Opuscar: https://github.com/lemomo-ai/lemo-opuscar (갤러리 https://lemomo-ai.github.io/lemo-opuscar/)
- Claude Code 플러그인. 영상 생성 AI 없이 HTML 캔버스·WebGL을 프레임마다 그려 만드는 방식이라 우리(Remotion)와 원리가 같다. 다만 토큰을 쓴다 (영상 1개 30~60분)
- 코드는 MIT, 스타일·시범 영상은 **CC BY 4.0** → 그대로 가져다 쓰면 영상 설명란에 출처를 적는다. 아이디어만 참고해 우리 코드로 다시 짜면 출처는 안 적어도 된다
- 스타일마다 `styles/<이름>/STYLE.md`(어떻게 보이고 들리는지)와 시범 영상이 있다

## 쓰는 법 (정해 둔 것)
1. 그 시대 편을 기획할 때 이 표를 먼저 본다
2. 해당 스타일의 `STYLE.md`와 시범 영상을 보고, **우리 코드(src/draft, kit.tsx)로 다시 짠다** - 플러그인을 우리 제작에 그대로 쓰지 않는다
3. 시험은 저장소와 분리된 폴더에서. 남의 플러그인·코드는 설치하기 전에 먼저 읽는다
4. 한 편 전체가 아니라 한 장면(예: 처형을 그림자극으로)부터 시험해 보고, 사용자에게 저화질로 보여 준 뒤 정한다
5. 2026-10-28엔 토큰이 적어 시험 영상은 안 만들었다

## 같이 가져온 것 (이미 하네스에 들어감)
- Lemo-Opuscar 연출 가이드(`DIRECTOR.md`)의 "자주 하는 실수" → `check-draft.py`: 너무 작은 인물·화면 끝 인물, 검은 화면 0.5초+, 어두운 화면 3초+, 대비 낮은 화면 3초+ 경고
- "리듬은 음악 박자부터" → `kit.tsx` beatSnap: 장면 전환을 브금 박에 ±4프레임 안에서 붙임 (`public/bgm/tempo.json`)
- 안 가져온 것: 글자 읽힘 검사(우리 화면 글자는 숫자·연도뿐), 필름 질감 요령(우리는 안 씀)
